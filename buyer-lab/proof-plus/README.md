## Try four editable synthetic scenarios

1. **Webhook resilience:** tenant-scoped event receipt, retry/replay rejection and invalid-input handling. No live HMAC verification.
2. **Data reconciliation:** duplicate, missing and mismatching data with exact integer cents. No production database.
3. **Authorization policy:** issuer, audience, scope, tenant and time checks on synthetic claims. No cryptographic JWT signature verification.
4. **Release policy:** fail-closed sample, latency/error-rate gates and approval checks. No real deployment, production rollback or SLA.

Each scenario offers a passing and failing fixture plus **Compare both outcomes** and **Export comparison JSON**. Synthetic examples run entirely in the browser, with no backend, vendor API key or customer-data collection.
