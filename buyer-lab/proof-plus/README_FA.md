## چه چیزهایی آزمایش می‌شوند؟

چهار سناریوی ساختگی و قابل‌ویرایش: Webhook و کنترل درخواست تکراری، تطبیق داده، کنترل مجوز، و معیار پذیرش انتشار. برای هر سناریو می‌توان حالت درست و خطادار را کنار هم اجرا کرد و خروجی JSON گرفت. هیچ‌کدام به API واقعی، پایگاه دادهٔ مشتری یا عملیات تولیدی متصل نیستند.

## شواهد آزمون

```bash
node --test tests/comparison.test.mjs tests/engine.test.mjs tests/site-static.test.mjs
```

در ۱۸ نوامبر ۲۰۲۶، **۷۸ آزمون خودکار موفق، صفر شکست و صفر Skip** ثبت شد. آزمایش تعاملی مرورگر آفلاین در اندازه‌های دسکتاپ و موبایل نیز انجام شده است؛ این به معنی ممیزی مستقل یا تأیید همه‌جانبهٔ سایت آنلاین نیست.

**۸۵۸ اجرای آزمون** مربوط به حسابرسی جداگانهٔ ۴۴ بستهٔ منبع است و شامل همپوشانی آزمون‌های بسته‌ها می‌شود. این رقم معادل ۸۵۸ آزمون منحصربه‌فرد یا ۴۴ محصول تأییدشده برای واگذاری تجاری نیست.
