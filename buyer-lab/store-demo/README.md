# ARAZVERA Storefront Sandbox (Buyer Lab)

URL: https://arazvera-technologies.github.io/buyer-lab/store-demo/

Public demonstration only — NOT an operational store.

## What works
- Loads **exactly 44** original source-bank SKU names and public proof metadata from the existing \`../catalog.json\`.
- Search, level filter, featured sorting, product details, demo bag, simulated card approval and downloadable text-only demonstration receipt.
- No card entry, wallets, API calls to a processor, cookies, submitted customer data, server-side orders, license issue, or private source downloads.
- The L2/L3/L4/BUNDLE demo prices are intentionally arbitrary placeholders ($299/$1,299/$2,999/$1,999). NOT genuine offers or quotes.
- No files, hashes or repository paths for the private isolated-delivery repositories are embedded anywhere.

## Safety / go-live gate
No live transaction or private ZIP access until product IP/OSS rights and applicable compliance are reviewed, a permitted payment service has approved the real seller, license and acceptance terms are agreed, settlement/chargeback handling is implemented, and the delivery gate is independently tested. Do NOT turn a simulated checkout approval into a commercial release authorization.

This demo is hosted on existing GitHub Pages as a noncommercial user-interface prototype. Real e-commerce must be deployed on a platform which permits commerce; do not run actual paid checkout on GitHub Pages. Keep corporate homepage and existing Buyer Lab unaffected.
